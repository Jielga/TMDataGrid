# @jielga/tmdatagrid

A React data grid built on TanStack Table v9 and Mantine - always virtualized, with resizable, reorderable, sortable, filterable, hideable and pinnable columns.

- Documentation: <https://jielga.github.io/TMDataGrid/>
- Source, issues and the contributor guide: <https://github.com/Jielga/TMDataGrid>

```sh
npm install @jielga/tmdatagrid
```

The package ships its reference documentation under `docs/` and its TanStack Intent skills under `skills/`, so an agent working in a project that installs it can load both.
